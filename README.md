# How to do all the steps
1. Firstly, you need ubuntu settings and make sure ROS Jazzy already installed
2. Download httplib and opencv lib
3. Change directory with cd to the TugasOpenCV location
4. Copy and Paste this, "g++ src/main.cpp -o main -pthread pkg-config --cflags --libs opencv4"
5. Copy and Paste this, "./main"
6. Press "S"
7. Eat and take the pasta!
8. Enjoy!
